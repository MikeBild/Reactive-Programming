# Workshop Reactive Programming

## RxJS-Übungen

Für den Workshop „Reactive Programming mit RxJS“ liegen die Übungen im Ordner [`rxjs/`](rxjs): ein npm-Projekt mit Node.js 26, TypeScript strict, RxJS 7.8 und Vitest. Pro Lektion gibt es Startpunkt, Lösung und Tests, Zeit läuft im Test über den `TestScheduler`.

```sh
cd rxjs
npm ci
npm test
```

Details und die Liste der Lektionen stehen in [`rxjs/README.md`](rxjs/README.md). Das C#-Material mit Rx.NET unter `Examples/` bleibt unverändert.
